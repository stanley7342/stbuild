Build — 建置流程

4 / 11
1 選擇 Source Files 目錄
→
2 (選填) 選擇 Config File
→
3 選擇 Build Type
→
4 按 Build 或 F7
→
5 查看 Output Files

⚙️ 建置動作

  • Build — CMake configure + build，快捷鍵 F7
  • Clean — 清除 build 目錄輸出
  • Rebuild — Clean 後重新 Build

📋 Build Type

  • Debug — 含除錯符號（預設）
  • Release — 最佳化，無除錯符號
  • RelWithDebInfo — 最佳化 + 除錯符號
  • MinSizeRel — 最小體積

📦 Output Files — 自動偵測最新輸出

  • 掃描 build/ 目錄，依 修改時間 排序，顯示最新 .elf 與 .bin
  • 描述欄顯示最後修改時間，點擊可在檔案總管中定位

CMSIS-DAP Debug — 片上除錯

8 / 11
1 連接 CMSIS-DAP 偵錯器
→
2 Build 專案取得 ELF
→
3 按 Start Debug
→
4 OpenOCD 啟動於終端機
→
5 GDB 連接 :50000

🔧 自動偵測

  • ELF — build/ 內最新 .elf（依 mtime）
  • OpenOCD — tools/Debugger/OpenOCD/bin/win/
  • Script — tools/Debugger/OpenOCD/script/openocd_rt58x.sh
  • Target — 依 Device 設定自動選擇

🗺️ SoC → Target 對應

DeviceOpenOCD Target
rt581 / rt582 / rt583target/rt58x.cfg
rt584l / rt584h
rt584ha4 / rf1301		target/rt584.cfg

⚙️ Windows 啟動指令（等同 openocd_rt58x.sh）

& "…\OpenOCD\bin\win\openocd.exe" -s "…\script" -f interface/cmsis-dap.cfg -f "target/rt584.cfg" -c "gdb_port 50000; tcl_port 50001; telnet_port 50002"

Config Editor — Kconfig 設定編輯

9 / 11

📂 載入方式

  • 選擇 Source Files 目錄時自動偵測 .config / defconfig
  • 點擊 Build 區的 Config File 可手動選擇
  • 修改後按 Save 圖示儲存

🎨 顏色分類

  • ■ 紫色 — 區段標題（不可編輯）
  • ■ 綠色 ✓ — Bool = y（點擊切換）
  • ■ 紅色 ✗ — Bool = n（點擊切換）
  • ■ 藍色 — 字串值（點擊輸入）
  • ■ 黃色 — 數字值（點擊輸入）

📄 支援格式（Kconfig 風格）

# General Configuration
CONFIG_SOC_SERIES="rt584"
CONFIG_CPU_CORTEX_M33=y
CONFIG_SYS_CLOCK_HW_CYCLES_PER_SEC=32000000
